# Portfolio Generator 🚀

This is a simple Portfolio Generator built with **React + Vite**. Users can input their personal and professional information through a form, and the app dynamically renders a portfolio-style card based on the submitted data.

---

## 🛠 Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- HTML + CSS

---

## 📦 Installation

1. **Clone the repository**  
   ```bash
   git clone https://github.com/PawanBakle/Portfolio-Generator.git
   cd 'portfolio designs'
2. **Install dependencies
   Make sure you have Node.js and npm installed.**
    ```bash
    npm install
3. **Run the development server**
   ```bash
   npm run dev
4. **Open your browser and go to:**
   ```bash
   http://localhost:5173

**Project Structure**
  ```bash
  .
  ├── public/
  ├── src/
  │   ├── components/
  │   ├── App.jsx
  │   └── main.jsx
  ├── package.json
  └── vite.config.js


```

**Troubleshooting :**
If you get vite is not recognized, make sure to run:
  ```bash
  npm install
```

**If the app still doesn’t run, ensure you're in the correct directory with package.json.**
